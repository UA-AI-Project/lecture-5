## Evaluation Objectives

The first step to designing an offline experiment is define the evaluation objective(s).
An evaluation objective is typically formulated from the perspective of one (or more) stakeholders, for example, the platform, users and item providers. Each of these stakeholders has goals, that can be achieved by designing a recommender system that has certain desired properties. In an offline evaluation experiment, we want to evaluate whether an algorithm has more or less of the desired properties than a selection of other algorithms (the baselines).
If this is the case, the algorithm is better suited to our goal than any other algorithm.
